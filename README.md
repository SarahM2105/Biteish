# project overview 
this project is a web based restaurant booking and management system that provides 
- realtime reservations 
- personalised reccomendations 
- Accessibility aware searches 
- dashboard for 3 roles (customer, admin, owners)

The system is being developed with: React, Node.js/Express, PostgreSQL, Prisma, Socket.io and Redis
